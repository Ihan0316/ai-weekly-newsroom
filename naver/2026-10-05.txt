🧠 오늘의 퀴즈 (정보처리기사)
━━━━━━━━━━━━━━━━━━━━
[네트워크] 다음 중 TCP/IP 4계층 모델에서 인터넷 계층(Internet Layer)의 주요 역할로 가장 적절한 것은?
① 애플리케이션 간의 데이터 통신을 담당하고, 데이터 형식 변환을 처리한다.
② 프로세스 간의 신뢰성 있는 데이터 전송을 보장하거나, 비연결형 데이터 전송을 제공한다.
③ 네트워크 간의 패킷 라우팅을 담당하며, IP 주소를 사용하여 목적지까지 데이터를 전달한다.
④ 물리적인 매체를 통해 비트 스트림을 전송하고, 전기적/기계적 특성을 정의한다.

정답: 3번
해설: TCP/IP 4계층 모델에서 인터넷 계층은 네트워크 간의 패킷 전달을 담당합니다. IP 주소를 기반으로 데이터를 목적지까지 라우팅하는 핵심적인 역할을 수행합니다. 이를 통해 서로 다른 네트워크에 있는 호스트 간 통신이 가능해집니다.

━━━━━━━━━━━━━━━━━━━━
📖 오늘의 IT 용어
━━━━━━━━━━━━━━━━━━━━

• 데이터 레이크 (Data Lake) (IT)
  정형, 반정형, 비정형 등 모든 형태의 데이터를 원본 그대로 저장하는 대규모 저장소로, 나중에 분석이나 처리를 위해 활용된다.

• 페르소나 (Persona) (기획)
  제품이나 서비스를 이용할 가상의 사용자 캐릭터로, 실제 사용자의 특징과 행동 패턴을 대표하도록 상세하게 설정된다.

• CDN (Content Delivery Network) (IT)
  사용자가 웹 콘텐츠에 더 빠르게 접근할 수 있도록 지리적으로 분산된 서버 네트워크를 통해 콘텐츠를 전달하는 시스템이다.
