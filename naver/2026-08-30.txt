🧠 오늘의 퀴즈 (정보처리기사)
━━━━━━━━━━━━━━━━━━━━
[데이터베이스] 관계형 데이터베이스에서 테이블의 특정 속성(Attribute) 값이 유일하도록 보장하며, NULL 값은 허용하지만 중복은 허용하지 않는 제약조건은?
① PRIMARY KEY
② FOREIGN KEY
③ UNIQUE
④ NOT NULL

정답: 3번
해설: UNIQUE 제약조건은 특정 속성 값이 테이블 내에서 유일해야 함을 보장합니다. PRIMARY KEY와 달리 NULL 값을 허용하며, 여러 UNIQUE 제약조건을 한 테이블에 설정할 수 있습니다.

• 데이터 마이그레이션 (Data Migration) (IT)
  하나의 시스템에서 다른 시스템으로 데이터를 옮기는 과정으로, 일반적으로 데이터 형식 변환, 검증, 로드 등의 단계를 포함합니다.

• 도메인 네임 시스템 (DNS, Domain Name System) (IT)
  사람이 읽을 수 있는 도메인 이름을 컴퓨터가 이해하는 IP 주소로 변환해주는 시스템입니다.

• 스쿼시 (Squash) (개발)
  Git에서 여러 개의 커밋(commit)을 하나의 커밋으로 합치는 작업으로, 커밋 히스토리를 깔끔하게 정리하는 데 사용됩니다.
