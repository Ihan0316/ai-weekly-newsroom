🧠 오늘의 퀴즈 (정보처리기사)
━━━━━━━━━━━━━━━━━━━━
[데이터베이스] 관계형 데이터베이스에서 데이터의 중복을 최소화하고 무결성을 유지하기 위해 테이블을 여러 개의 작은 테이블로 분해하는 과정은 무엇인가?
① 인덱싱
② 정규화
③ 조인
④ 뷰 생성

정답: 2번
해설: 정규화는 데이터베이스 설계에서 중복을 줄이고 데이터 무결성을 향상시키는 과정입니다. 이를 통해 데이터 삽입, 삭제, 갱신 시 발생할 수 있는 이상 현상(Anomaly)을 방지합니다. 여러 정규형(1NF, 2NF, 3NF 등)이 있으며, 각 정규형은 특정 조건을 만족해야 합니다.

📖 오늘의 IT 용어
━━━━━━━━━━━━━━━━━━━━

• CDN (IT)
  사용자에게 웹 콘텐츠를 더 빠르고 효율적으로 전달하기 위해 지리적으로 분산된 서버 네트워크를 사용하는 기술입니다.

• RESTful API (개발)
  웹 서비스에서 자원을 이름으로 구분하여 해당 자원의 상태를 주고받는 모든 것을 의미하며, HTTP 메서드를 사용하여 자원을 조작하는 아키텍처 스타일입니다.

• MVP (기획)
  최소 기능 제품으로, 핵심 기능만을 포함하여 시장에 빠르게 출시하고 고객 피드백을 통해 제품을 개선해 나가는 전략입니다.
