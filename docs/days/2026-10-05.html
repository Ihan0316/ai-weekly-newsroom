다음 중 TCP/IP 4계층 모델에서 인터넷 계층(Internet Layer)의 주요 역할로 가장 적절한 것은?

  1. ①애플리케이션 간의 데이터 통신을 담당하고, 데이터 형식 변환을 처리한다.
  2. ②프로세스 간의 신뢰성 있는 데이터 전송을 보장하거나, 비연결형 데이터 전송을 제공한다.
  3. ③네트워크 간의 패킷 라우팅을 담당하며, IP 주소를 사용하여 목적지까지 데이터를 전달한다.
  4. ④물리적인 매체를 통해 비트 스트림을 전송하고, 전기적/기계적 특성을 정의한다.
