#소프트웨어 공학

소프트웨어 개발 프로젝트에서 요구사항을 분석하는 과정에서 사용되는 기법 중, 사용자 인터뷰나 설문조사를 통해 얻은 비정형적인 데이터를 구조화하고 분류하여 의미 있는 정보로 도출하는 기법은 무엇인가?

보기를 눌러 정답을 확인하세요.

정답: ④

콘텐츠 분석은 사용자 인터뷰, 설문조사, 문서 등에서 얻은 비정형적인 텍스트 데이터를 체계적으로 분석하여 핵심적인 요구사항이나 패턴을 도출하는 기법입니다. 이는 정성적인 데이터를 정량적으로 이해하고 구조화하는 데 유용합니다. 다른 보기들은 주로 시스템의 기능, 데이터 흐름, 데이터 구조를 시각적으로 모델링하는 데 사용됩니다.

03
IT · 개발 · 기획 용어
  • IT 플랫폼 엔지니어링 (Platform Engineering) 개발자가 애플리케이션을 더 효율적으로 빌드하고 배포할 수 있도록, 클라우드 인프라 및 도구를 통합하여 자체 서비스 플랫폼을 구축하고 관리하는 분야입니다.
  • 개발 폴리글랏 퍼시스턴스 (Polyglot Persistence) 애플리케이션의 다양한 데이터 요구사항에 맞춰 여러 종류의 데이터베이스(예: 관계형, NoSQL)를 함께 사용하는 아키텍처 접근 방식입니다.
  • 기획 린치핀 (Linchpin) 전체 시스템이나 프로젝트에서 핵심적인 역할을 수행하여, 이것 없이는 다른 부분들이 제대로 작동할 수 없는 매우 중요한 요소나 인물을 의미합니다.
