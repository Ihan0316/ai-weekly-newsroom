#소프트웨어 공학

소프트웨어 설계 원칙 중, '단일 책임 원칙(Single Responsibility Principle, SRP)'에 대한 설명으로 가장 적절한 것은?

보기를 눌러 정답을 확인하세요.

정답: ①

단일 책임 원칙(SRP)은 객체 지향 설계의 SOLID 원칙 중 하나로, 한 클래스는 하나의 책임만 가져야 함을 의미합니다. 즉, 클래스를 변경하는 이유는 오직 하나여야 한다는 것입니다. 이는 코드의 가독성, 유지보수성, 테스트 용이성을 높이는 데 기여합니다.

03
IT · 개발 · 기획 용어
  • IT 세션 하이재킹 (Session Hijacking) 네트워크 통신에서 합법적인 사용자 세션을 가로채어 해당 세션의 권한을 불법적으로 획득하는 공격 기법입니다.
  • 개발 도메인 주도 설계 (Domain-Driven Design, DDD) 소프트웨어 개발에서 비즈니스 도메인 모델을 중심으로 아키텍처를 설계하고 구현하는 접근 방식입니다.
  • 기획 바이럴 루프 (Viral Loop) 기존 사용자가 새로운 사용자를 유입시키고, 그 새로운 사용자가 다시 다른 사용자를 유입시키는 반복적인 과정을 통해 제품이나 서비스가 확산되는 성장 메커니즘입니다.
