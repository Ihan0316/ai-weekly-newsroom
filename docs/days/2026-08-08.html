#운영체제

다음 중 운영체제의 메모리 관리 기법 중 하나인 세그먼테이션(Segmentation)에 대한 설명으로 가장 적절한 것은?

  1. ①프로세스를 고정된 크기의 페이지로 나누어 물리 메모리에 불연속적으로 적재하는 기법이다.
  2. ②프로세스를 논리적인 의미 단위인 세그먼트로 나누어 물리 메모리에 적재하는 기법이다.
  3. ③메모리 단편화 문제를 해결하기 위해 주기억장치에 분산된 빈 공간들을 하나로 합치는 작업이다.
  4. ④CPU 스케줄링 기법 중 하나로, 각 프로세스에 일정한 시간 할당량을 주어 번갈아 실행하는 방식이다.

정답: ②

세그먼테이션은 프로세스를 페이지와 같이 고정된 크기가 아닌, 코드, 데이터, 스택 등과 같은 논리적인 의미 단위인 세그먼트로 나누어 관리하는 메모리 관리 기법입니다. 이는 사용자가 프로그램을 바라보는 방식과 유사하여 프로그래머에게 더 직관적인 메모리 관리를 제공합니다. 각 세그먼트는 크기가 다를 수 있습니다.

IT · 개발 · 기획 용어
  • IT 컨텍스트 스위칭 (Context Switching) CPU가 하나의 프로세스 또는 스레드에서 다른 프로세스 또는 스레드로 실행 제어를 전환할 때 발생하는 작업으로, 이전 프로세스의 상태를 저장하고 새 프로세스의 상태를 로드하는 과정을 의미합니다.
  • 기획 아이코닉 디자인 (Iconic Design) 제품이나 서비스의 특징을 상징적으로 표현하는 디자인으로, 사용자에게 강렬하고 기억하기 쉬운 인상을 주어 브랜드 인지도를 높이는 데 활용됩니다.
  • 개발 옵저버빌리티 (Observability) 시스템의 내부 상태를 외부에서 얼마나 잘 추론할 수 있는지를 나타내는 지표로, 로그, 메트릭, 트레이스 등을 통해 시스템의 동작을 이해하고 문제를 진단하는 능력을 의미합니다.
