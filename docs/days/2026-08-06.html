  • 개발 멱등성 (Idempotence) 동일한 작업을 여러 번 수행하더라도 항상 동일한 결과를 생성하거나 시스템의 상태를 동일하게 유지하는 특성을 의미한다.
  • 개발 도메인 주도 설계 (Domain-Driven Design, DDD) 소프트웨어 개발 시 비즈니스 도메인을 중심으로 모델을 설계하고 구현하여 복잡한 비즈니스 로직을 효과적으로 다루는 접근 방식이다.
  • 기획 퍼널 분석 (Funnel Analysis) 사용자가 특정 목표(예: 구매, 회원가입)에 도달하기까지 거치는 일련의 단계를 시각화하고 각 단계별 전환율을 분석하여 최적화 기회를 찾는 방법이다.
