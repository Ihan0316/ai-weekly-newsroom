#운영체제

운영체제에서 메모리 관리 기법 중, '세그먼테이션(Segmentation)'에 대한 설명으로 가장 적절한 것은?

보기를 눌러 정답을 확인하세요.

정답: ②

세그먼테이션은 프로세스의 논리적 주소 공간을 프로그램의 논리적 구조에 따라 세그먼트라는 가변 크기의 단위로 나누어 관리하는 기법입니다. 이는 사용자가 프로그램을 모듈 단위로 인식하고 관리할 수 있도록 돕습니다. 각 세그먼트는 고유한 시작 주소와 크기를 가지며, 메모리 보호와 공유에 유용합니다.

03
IT · 개발 · 기획 용어
  • 개발 도메인 주도 설계 (Domain-Driven Design, DDD) 소프트웨어 개발에서 비즈니스 도메인을 중심으로 모델을 구축하고, 이 모델을 코드에 직접 반영하여 복잡한 비즈니스 로직을 효과적으로 관리하는 접근 방식입니다.
  • 개발 카나리 배포 (Canary Deployment) 새로운 버전의 소프트웨어를 전체 사용자에게 한 번에 배포하는 대신, 소수의 사용자에게 먼저 배포하여 문제 발생 여부를 확인한 후 점진적으로 배포를 확대하는 전략입니다.
  • 기획 피처 토글 (Feature Toggle) 코드 변경 없이 특정 기능의 활성화 또는 비활성화를 제어할 수 있는 기술로, A/B 테스트, 점진적 기능 배포 등에 활용됩니다.
