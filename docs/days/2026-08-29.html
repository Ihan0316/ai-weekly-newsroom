#데이터베이스

관계형 데이터베이스에서 데이터 무결성 제약조건 중, 특정 속성 값이 NULL을 허용하지 않도록 강제하는 제약조건은?

  1. ①기본 키 제약조건 (Primary Key Constraint)
  2. ②외래 키 제약조건 (Foreign Key Constraint)
  3. ③NOT NULL 제약조건
  4. ④고유 제약조건 (Unique Constraint)

보기를 클릭해 정답을 확인하세요.

정답: ③

NOT NULL 제약조건은 특정 속성(컬럼)에 NULL 값이 저장되는 것을 방지하여 데이터의 완전성을 유지합니다. 이는 데이터의 누락을 막고, 해당 속성에 항상 유효한 값이 존재하도록 보장하는 역할을 합니다.
