#데이터베이스

관계형 데이터베이스에서 데이터를 조회할 때, 하나 이상의 테이블로부터 원하는 데이터를 추출하기 위해 사용되는 SQL 명령은 무엇인가?

  1. ①INSERT
  2. ②UPDATE
  3. ③DELETE
  4. ④SELECT

보기를 클릭해 정답을 확인하세요.

정답: ④

SQL의 SELECT 명령은 데이터베이스에서 데이터를 조회하는 데 사용됩니다. 이를 통해 사용자는 특정 조건을 만족하는 데이터를 추출하거나, 여러 테이블을 조인하여 복합적인 정보를 얻을 수 있습니다. INSERT, UPDATE, DELETE는 각각 데이터 삽입, 수정, 삭제에 사용됩니다.
