#데이터베이스

관계형 데이터베이스에서 여러 테이블 간의 중복 데이터를 제거하고 데이터의 일관성 및 무결성을 확보하기 위해 테이블을 구조화하는 과정은 무엇인가?

  1. ①트랜잭션 관리
  2. ②인덱싱
  3. ③정규화
  4. ④뷰 생성

보기를 클릭해 정답을 확인하세요.

정답: ③

정규화(Normalization)는 관계형 데이터베이스의 설계 단계에서 중복을 최소화하고 데이터의 무결성을 높이기 위해 테이블을 분해하거나 재구성하는 과정입니다. 이를 통해 데이터 삽입, 삭제, 갱신 시 발생할 수 있는 이상 현상을 방지합니다. 트랜잭션 관리는 데이터의 일관성을 유지하기 위한 것이고, 인덱싱은 검색 속도 향상, 뷰 생성은 보안 및 편의성 제공이 주 목적입니다.

IT · 개발 · 기획 용어
  • 개발 도메인 주도 설계 (DDD) 소프트웨어 개발에서 비즈니스 도메인 전문가와 개발자가 협력하여 비즈니스 로직을 명확히 모델링하고, 해당 모델을 소프트웨어 구현에 반영하는 접근 방식입니다.
  • 개발 옵저버 패턴 객체 지향 디자인 패턴 중 하나로, 한 객체의 상태 변화에 따라 다른 객체들에게 자동으로 알림을 보내는 일대다 의존성을 정의하는 패턴입니다.
  • 기획 피처 플래그 (Feature Flag) 소프트웨어 기능을 코드 배포와 독립적으로 제어할 수 있게 해주는 기술로, 특정 기능을 켜거나 끌 수 있어 A/B 테스트나 점진적 배포에 활용됩니다.
