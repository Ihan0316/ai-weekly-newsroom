#데이터베이스

데이터베이스 시스템에서 여러 사용자가 동시에 동일한 데이터에 접근하여 발생하는 문제점을 해결하고 데이터의 일관성과 무결성을 유지하기 위한 기법은 무엇인가?

보기를 눌러 정답을 확인하세요.

정답: ③

트랜잭션 관리는 데이터베이스의 동시성 제어 및 복구 기능을 담당하여 다중 사용자 환경에서 데이터의 일관성과 무결성을 보장합니다. 이를 통해 여러 사용자가 동시에 데이터를 조작하더라도 문제가 발생하지 않도록 합니다. 정규화는 데이터 중복을 줄이고, 인덱싱은 검색 성능을 향상시키며, 백업 및 복구는 데이터 손실에 대비하는 기법입니다.

03
IT · 개발 · 기획 용어
  • 개발 도메인 주도 설계 (DDD) 복잡한 소프트웨어 시스템을 개발할 때, 비즈니스 핵심 도메인과 그 로직에 집중하여 설계를 이끌어 나가는 접근 방식입니다.
  • 개발 컨테이너 오케스트레이션 (Container Orchestration) 다수의 컨테이너화된 애플리케이션의 배포, 관리, 스케일링 및 네트워킹을 자동화하는 기술입니다.
  • 기획 MVP (Minimum Viable Product) 최소 기능 제품으로, 핵심 기능만을 담아 시장에 빠르게 출시하여 사용자 피드백을 통해 제품을 개선해 나가는 전략입니다.
