#소프트웨어 공학

소프트웨어 개발에서 '형상 관리(Configuration Management)'의 주요 목적과 가장 거리가 먼 것은?

보기를 눌러 정답을 확인하세요.

정답: ④

형상 관리는 소프트웨어 개발 과정에서 발생하는 변경 사항을 체계적으로 관리하여 소프트웨어의 무결성과 일관성을 유지하는 것을 목표로 합니다. 버전 관리, 변경 제어, 형상 식별 등이 주요 활동이며, 사용자 만족도 측정은 주로 요구사항 분석이나 테스트 단계에서 다루는 내용입니다.

03
IT · 개발 · 기획 용어
  • 개발 블로커 (Blocker) 소프트웨어 개발 과정에서 특정 작업을 진행할 수 없도록 완전히 막는 심각한 문제나 이슈를 의미한다.
  • 개발 도메인 주도 설계 (DDD, Domain-Driven Design) 소프트웨어 개발 시 실제 비즈니스 도메인에 대한 깊은 이해를 바탕으로 도메인 모델을 구축하고 이를 소프트웨어 아키텍처에 반영하는 접근 방식이다.
  • 기획 온보딩 (Onboarding) 신규 사용자가 제품이나 서비스를 처음 접했을 때, 쉽고 효과적으로 적응하고 활용할 수 있도록 돕는 일련의 과정을 의미한다.
