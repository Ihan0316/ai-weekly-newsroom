#소프트웨어 공학

소프트웨어 설계 원칙 중, '개방-폐쇄 원칙(Open/Closed Principle, OCP)'에 대한 설명으로 가장 적절한 것은?

보기를 눌러 정답을 확인하세요.

정답: ②

개방-폐쇄 원칙(OCP)은 소프트웨어 개체가 기능 확장을 위해서는 열려 있어야 하지만, 기존 코드를 수정하지 않고 확장이 가능하도록 닫혀 있어야 한다는 원칙입니다. 이는 시스템 변경 시 기존 코드에 미치는 영향을 최소화하여 유지보수성을 높이는 데 기여합니다.

03
IT · 개발 · 기획 용어
  • 개발 멱등성 (Idempotency) 동일한 연산을 여러 번 수행하더라도 항상 같은 결과를 반환하며, 시스템의 상태를 변경하지 않는 특성을 의미한다.
  • 개발 백프레셔 (Backpressure) 데이터 처리 시스템에서 생산자의 데이터 생성 속도가 소비자의 처리 속도보다 빠를 때, 생산자의 속도를 조절하여 시스템 과부하를 방지하는 메커니즘이다.
  • IT 블루/그린 배포 (Blue/Green Deployment) 기존 운영 환경(블루)과 동일한 새로운 환경(그린)을 미리 준비한 후, 트래픽을 한 번에 전환하여 무중단 배포를 가능하게 하는 전략이다.
