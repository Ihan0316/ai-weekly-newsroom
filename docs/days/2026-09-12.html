#소프트웨어 공학

소프트웨어 아키텍처 패턴 중, 애플리케이션의 관심사를 데이터(Model), 사용자 인터페이스(View), 그리고 이 둘을 연결하는 로직(Controller)으로 분리하여 개발하는 방식은 무엇인가?

  1. ①MVVM (Model-View-ViewModel)
  2. ②MVC (Model-View-Controller)
  3. ③MVP (Model-View-Presenter)
  4. ④Pipe-Filter

보기를 클릭해 정답을 확인하세요.

정답: ②

MVC(Model-View-Controller)는 애플리케이션을 Model, View, Controller 세 가지 역할로 나누어 개발하는 아키텍처 패턴입니다. Model은 데이터를, View는 사용자 인터페이스를, Controller는 Model과 View 사이의 상호작용 및 로직을 담당하여 관심사의 분리를 통해 유지보수성과 확장성을 높입니다.

IT · 개발 · 기획 용어
  • 개발 컨테이너 오케스트레이션 (Container Orchestration) 다수의 컨테이너를 효율적으로 배포, 관리, 스케일링하고 자동화하는 기술을 의미한다.
  • IT 서버리스 (Serverless) 개발자가 서버 관리에 신경 쓰지 않고 애플리케이션 개발에만 집중할 수 있도록 클라우드 제공업체가 서버를 관리해주는 컴퓨팅 실행 모델이다.
  • 기획 그로스 해킹 (Growth Hacking) 제품이나 서비스의 성장을 목표로, 마케팅과 기술을 결합하여 다양한 실험과 분석을 통해 효율적인 성장 전략을 찾아내는 접근 방식이다.
