#소프트웨어 공학

소프트웨어 개발에서 '디자인 패턴(Design Pattern)'에 대한 설명으로 가장 적절한 것은?

보기를 눌러 정답을 확인하세요.

정답: ②

디자인 패턴은 소프트웨어 설계 시 자주 발생하는 문제들을 해결하기 위한 검증된 해결책을 의미합니다. 이는 특정 문제 상황에서 효율적이고 재사용 가능한 구조를 제공하여 개발 생산성과 유지보수성을 향상시킵니다. 단순히 문법이나 알고리즘, UI 디자인 규칙과는 다른 개념입니다.

03
IT · 개발 · 기획 용어
  • 기획 플라이휠 효과 (Flywheel Effect) 초기에는 큰 노력이 필요하지만, 한번 가속도가 붙으면 적은 노력으로도 지속적인 성장과 선순환을 만들어내는 비즈니스 모델이나 전략을 의미한다.
  • 개발 매니페스트 파일 (Manifest File) 소프트웨어 패키지나 애플리케이션의 메타데이터(버전, 구성 요소, 권한 등)를 정의하여 시스템이 해당 소프트웨어를 올바르게 배포, 실행, 관리할 수 있도록 돕는 파일이다.
  • IT 퍼블릭 클라우드 (Public Cloud) 클라우드 서비스 제공업체가 소유하고 운영하는 컴퓨팅 자원(서버, 스토리지, 네트워크 등)을 인터넷을 통해 일반 대중에게 제공하는 클라우드 배포 모델이다.
