#운영체제

운영체제에서 여러 프로세스가 동시에 실행될 때, 각 프로세스가 독립적인 주소 공간을 가지도록 하여 다른 프로세스의 메모리 영역을 침범하지 않도록 보호하는 기법은?

  1. ①페이징(Paging)
  2. ②세그먼테이션(Segmentation)
  3. ③메모리 보호(Memory Protection)
  4. ④스와핑(Swapping)

보기를 클릭해 정답을 확인하세요.

정답: ③

메모리 보호는 운영체제에서 각 프로세스가 할당받은 메모리 영역만 접근하도록 제한하여, 다른 프로세스의 메모리 영역을 침범하거나 운영체제 영역을 손상시키는 것을 방지하는 기법입니다. 이는 시스템의 안정성과 보안을 유지하는 데 필수적입니다. 페이징이나 세그먼테이션은 메모리 관리 기법의 일종이지만, 그 자체로 보호 기능을 직접적으로 제공하는 것은 아닙니다.

03
IT · 개발 · 기획 용어
  • IT 트랜잭션 격리 수준 (Transaction Isolation Level) 데이터베이스에서 여러 트랜잭션이 동시에 실행될 때, 한 트랜잭션이 다른 트랜잭션의 변경 내용을 어느 시점까지 볼 수 있을지를 정의하는 수준이다.
  • 개발 서버리스 아키텍처 (Serverless Architecture) 개발자가 서버를 직접 관리할 필요 없이 코드만 작성하여 배포하면 클라우드 공급자가 서버 운영을 전적으로 담당하는 아키텍처 방식이다.
  • 기획 린치핀 (Linchpin) 어떤 시스템이나 조직에서 핵심적인 역할을 수행하며, 없으면 전체가 제대로 작동하지 않는 매우 중요한 요소나 사람을 의미한다.
