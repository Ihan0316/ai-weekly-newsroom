#운영체제

운영체제에서 프로세스 스케줄링 기법 중, CPU 사용 시간이 긴 프로세스에게 불리하며, 응답 시간(Response Time)이 중요한 대화형 시스템에 적합한 기법은?

  1. ①FCFS (First-Come, First-Served)
  2. ②SJF (Shortest Job First)
  3. ③Priority Scheduling
  4. ④Round Robin

보기를 클릭해 정답을 확인하세요.

정답: ④

라운드 로빈(Round Robin) 스케줄링은 각 프로세스에 일정 시간(Time Quantum)을 할당하고, 이 시간 안에 작업을 완료하지 못하면 다음 프로세스에게 CPU를 넘겨주는 방식입니다. 이는 모든 프로세스가 공평하게 CPU 시간을 할당받아 응답 시간을 최소화할 수 있어 대화형 시스템에 유리합니다. 반면 CPU 사용 시간이 긴 프로세스는 여러 번 문맥 교환을 겪어야 하므로 불리할 수 있습니다.
