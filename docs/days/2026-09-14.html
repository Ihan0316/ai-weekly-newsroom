#데이터베이스

관계형 데이터베이스에서 여러 테이블의 데이터를 효율적으로 조회하기 위해, 미리 정의된 질의(Query)의 결과를 가상 테이블 형태로 저장해두는 객체는 무엇인가?

  1. ①인덱스(Index)
  2. ②뷰(View)
  3. ③트리거(Trigger)
  4. ④저장 프로시저(Stored Procedure)

보기를 클릭해 정답을 확인하세요.

정답: ②

뷰(View)는 하나 이상의 테이블로부터 유도된 가상 테이블입니다. 실제 데이터는 뷰에 저장되지 않고, 뷰를 통해 접근할 때마다 원본 테이블에서 데이터를 가져와 보여줍니다. 복잡한 쿼리를 단순화하고 보안을 강화하는 데 사용됩니다.

03
IT · 개발 · 기획 용어
  • 개발 도메인 지향 설계 (Domain-Oriented Design) 소프트웨어 개발 시 비즈니스 도메인의 복잡성을 관리하고, 실제 비즈니스 로직에 집중하여 설계하는 접근 방식입니다.
  • 개발 카나리 배포 (Canary Deployment) 새로운 버전의 소프트웨어를 소수의 사용자에게 먼저 배포하여 안정성을 확인한 후, 점진적으로 전체 사용자에게 확대하는 배포 전략입니다.
  • 기획 피벗 테이블 (Pivot Table) 대량의 데이터를 요약하고 분석하기 위해 데이터를 다양한 관점으로 재구성하여 보여주는 도구입니다.
