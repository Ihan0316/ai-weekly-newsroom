IT · 개발 · 기획 용어
  • IT CDN (Content Delivery Network) 사용자의 지리적 위치와 가까운 서버에서 콘텐츠를 제공하여 웹 서비스의 로딩 속도를 향상시키는 분산 서버 네트워크 시스템입니다.
  • 개발 테크 스택 (Tech Stack) 소프트웨어 애플리케이션을 개발하고 배포하는 데 사용되는 프로그래밍 언어, 프레임워크, 데이터베이스, 서버 등의 기술 조합을 의미합니다.
  • 기획 온보딩 (Onboarding) 신규 사용자나 고객이 제품 또는 서비스를 처음 접했을 때, 쉽고 효과적으로 적응하고 활용할 수 있도록 돕는 일련의 과정을 말합니다.
