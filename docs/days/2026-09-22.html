정답: ②

DAO(Data Access Object) 패턴은 데이터베이스나 영구 저장소에 접근하는 코드를 추상화하여 캡슐화하는 디자인 패턴입니다. 이를 통해 데이터 접근 로직과 비즈니스 로직을 분리하여 유지보수성과 유연성을 높일 수 있습니다.

03
IT · 개발 · 기획 용어
  • 개발 쿼리 최적화 (Query Optimization) 데이터베이스 질의(Query)의 실행 계획을 분석하고 개선하여 데이터 조회 및 처리 성능을 향상시키는 과정입니다.
  • IT 블로킹 (Blocking) 한 프로세스나 스레드가 다른 프로세스나 스레드의 작업이 완료될 때까지 대기하는 상태를 의미합니다.
  • 기획 린치핀 (Linchpin) 조직이나 프로젝트에서 핵심적인 역할을 수행하여 전체 시스템이 제대로 작동하게 하는 매우 중요한 요소나 인물을 지칭합니다.
