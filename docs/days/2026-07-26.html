#운영체제

운영체제에서 메모리 관리 기법 중, 물리 메모리를 여러 개의 고정된 크기 블록(프레임)으로 나누고, 프로세스의 논리 주소 공간을 같은 크기의 블록(페이지)으로 나누어 관리하는 기법은 무엇인가?

  1. ①세그먼테이션(Segmentation)
  2. ②페이징(Paging)
  3. ③스와핑(Swapping)
  4. ④단일 연속 할당(Single Contiguous Allocation)

보기를 클릭해 정답을 확인하세요.

정답: ②

페이징은 물리 메모리(프레임)와 논리 주소 공간(페이지)을 고정된 크기로 나누어 관리하는 기법입니다. 이를 통해 외부 단편화를 해결하고 가상 메모리 구현의 기반이 됩니다. 세그먼테이션은 가변적인 크기로 나누는 방식입니다.
