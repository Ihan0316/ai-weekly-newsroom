#데이터베이스

관계형 데이터베이스에서 테이블 간의 관계를 설정할 때, 한 테이블의 기본 키(Primary Key)가 다른 테이블의 속성으로 사용되어 두 테이블을 연결하는 역할을 하는 키는 무엇인가?

  1. ①후보 키(Candidate Key)
  2. ②대체 키(Alternate Key)
  3. ③외래 키(Foreign Key)
  4. ④슈퍼 키(Super Key)

보기를 클릭해 정답을 확인하세요.

정답: ③

외래 키(Foreign Key)는 다른 테이블의 기본 키를 참조하여 테이블 간의 관계를 설정하고 데이터의 무결성을 유지하는 데 사용됩니다. 이를 통해 두 테이블의 데이터를 연결하고 조인할 수 있습니다. 다른 보기들은 테이블 내에서 튜플을 고유하게 식별하는 데 사용되는 키들입니다.

IT · 개발 · 기획 용어
  • IT 블록체인 (Blockchain) 분산원장기술(DLT)의 한 형태로, 거래 기록을 '블록'이라는 단위로 묶어 체인처럼 연결하고 암호화하여 분산 네트워크 참여자들이 공유하고 검증하는 기술입니다.
  • 개발 프레임워크 (Framework) 소프트웨어 개발을 위한 기본적인 구조와 공통 기능을 제공하여, 개발자가 애플리케이션의 핵심 로직에 집중할 수 있도록 돕는 재사용 가능한 코드 집합입니다.
  • 기획 린 스타트업 (Lean Startup) 최소 기능 제품(MVP)을 빠르게 출시하고 고객 피드백을 통해 제품을 반복적으로 개선해나가면서 시장의 불확실성을 최소화하는 스타트업 경영 방식입니다.
