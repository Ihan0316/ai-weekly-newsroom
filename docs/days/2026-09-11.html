#운영체제

운영체제에서 프로세스가 실행 중에 참조하려는 데이터나 코드가 물리 메모리에 없는 경우 발생하는 현상은 무엇인가?

  1. ①인터럽트 (Interrupt)
  2. ②페이지 폴트 (Page Fault)
  3. ③데드락 (Deadlock)
  4. ④세마포어 (Semaphore)

보기를 클릭해 정답을 확인하세요.

정답: ②

페이지 폴트(Page Fault)는 프로세스가 참조하려는 페이지가 현재 물리 메모리에 로드되어 있지 않을 때 발생하는 현상입니다. 운영체제는 이 경우 보조 기억 장치에서 해당 페이지를 물리 메모리로 가져와 프로세스가 계속 실행될 수 있도록 합니다. 이는 가상 메모리 시스템의 핵심 구성 요소 중 하나입니다.

IT · 개발 · 기획 용어
  • IT 플랫폼 엔지니어링 (Platform Engineering) 개발자가 애플리케이션 개발에 집중할 수 있도록 인프라, 도구, 자동화된 워크플로우를 통합하여 셀프서비스 개발자 플랫폼을 구축하는 분야이다.
  • 기획 다크 패턴 (Dark Pattern) 사용자를 속여 특정 행동을 유도하거나 원치 않는 결정을 내리게 만드는 교묘한 사용자 인터페이스 디자인을 의미한다.
  • 개발 쿠버네티스 (Kubernetes) 컨테이너화된 워크로드와 서비스를 자동으로 배포, 스케일링 및 관리해주는 오픈소스 시스템이다.
