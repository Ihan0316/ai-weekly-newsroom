#소프트웨어 공학

소프트웨어 개발 과정에서 외부 시스템과의 연동이나 복잡한 비즈니스 로직을 처리하는 과정에서 발생할 수 있는 오류를 미리 예측하고, 시스템이 비정상적으로 종료되지 않도록 안정적으로 대응하는 기법은 무엇인가?

보기를 눌러 정답을 확인하세요.

정답: ②

예외 처리는 프로그램 실행 중 발생할 수 있는 비정상적인 상황(예외)에 대비하여 프로그램이 중단되지 않고 적절하게 대응하도록 하는 프로그래밍 기법입니다. 이를 통해 시스템의 안정성과 견고성을 높일 수 있습니다. 로깅은 시스템의 동작 기록을 남기는 것이고, 디버깅은 오류를 찾아 수정하는 과정이며, 테스팅은 소프트웨어의 품질을 확인하는 활동입니다.

03
IT · 개발 · 기획 용어
  • 개발 CQRS (Command Query Responsibility Segregation) 읽기(Query) 작업과 쓰기(Command) 작업을 위한 모델을 분리하여 사용하는 아키텍처 패턴으로, 복잡한 시스템에서 성능, 확장성, 보안을 개선하는 데 도움을 줍니다.
  • 개발 백프레셔 (Backpressure) 데이터 처리 시스템에서 생산자(Producer)의 데이터 생성 속도가 소비자(Consumer)의 처리 속도보다 빠를 때, 소비자가 생산자에게 속도를 늦추도록 알리는 메커니즘입니다.
  • 개발 도메인 주도 설계 (Domain-Driven Design, DDD) 복잡한 소프트웨어 시스템을 개발할 때, 핵심 비즈니스 도메인과 그 로직에 집중하여 설계하는 접근 방식입니다.
