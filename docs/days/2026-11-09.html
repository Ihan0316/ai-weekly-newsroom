#데이터베이스

데이터베이스 설계 단계 중, 물리적 데이터베이스 설계에 대한 설명으로 가장 적절한 것은?

보기를 눌러 정답을 확인하세요.

정답: ④

물리적 데이터베이스 설계는 논리적 설계가 완료된 후 특정 DBMS의 특성과 성능을 최적화하기 위해 저장 구조, 접근 경로(파일 구성), 인덱스 등을 구체적으로 설계하는 단계입니다. 이는 데이터베이스의 실제 저장 방식과 효율적인 접근 방법을 결정합니다.

03
IT · 개발 · 기획 용어
  • 개발 도메인 주도 설계 (Domain-Driven Design, DDD) 소프트웨어 개발 시 비즈니스 도메인에 초점을 맞추고, 도메인 전문가와 개발자가 함께 도메인 모델을 구축하여 복잡한 비즈니스 로직을 효과적으로 반영하는 접근 방식이다.
  • 개발 옵저버 패턴 (Observer Pattern) 객체 지향 디자인 패턴 중 하나로, 한 객체의 상태 변화에 따라 다른 객체들에게 자동으로 알림을 보내는 일대다 의존성을 정의하는 패턴이다.
  • IT 카나리 배포 (Canary Deployment) 새로운 버전의 소프트웨어를 전체 사용자에게 한 번에 배포하는 대신, 소수의 사용자 그룹에게 먼저 배포하여 문제점을 파악하고 점진적으로 배포를 확대하는 전략이다.
