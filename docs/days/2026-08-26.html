#운영체제

운영체제에서 프로세스가 실행 중에 참조하는 페이지가 물리 메모리에 없는 경우 발생하는 현상은?

  1. ①스래싱(Thrashing)
  2. ②페이지 폴트(Page Fault)
  3. ③외부 단편화(External Fragmentation)
  4. ④내부 단편화(Internal Fragmentation)

보기를 클릭해 정답을 확인하세요.

정답: ②

페이지 폴트(Page Fault)는 프로세스가 참조하려는 페이지가 현재 물리 메모리에 적재되어 있지 않아 운영체제가 해당 페이지를 보조 기억 장치에서 물리 메모리로 가져와야 하는 상황을 의미합니다. 이는 가상 메모리 시스템에서 발생하는 정상적인 현상 중 하나입니다. 스래싱은 페이지 폴트가 너무 빈번하게 발생하여 시스템 성능이 저하되는 현상을 말합니다.
