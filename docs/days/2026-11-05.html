#운영체제

운영체제에서 여러 프로세스가 동시에 실행될 때, CPU 할당 시간을 아주 짧게 나누어 각 프로세스에 번갈아 할당함으로써 모든 프로세스가 동시에 실행되는 것처럼 보이게 하는 스케줄링 기법은 무엇인가?

보기를 눌러 정답을 확인하세요.

정답: ③

라운드 로빈 스케줄링은 각 프로세스에 시간 할당량(time quantum)을 부여하고, 이 시간 동안만 CPU를 사용하도록 합니다. 할당된 시간이 끝나면 프로세스는 CPU를 반납하고 다음 프로세스가 CPU를 사용하게 되며, 모든 프로세스가 한 번씩 실행되면 다시 처음 프로세스로 돌아와 반복됩니다. 이는 시분할 시스템에서 모든 프로세스가 공평하게 CPU를 사용할 수 있도록 하여 대화식 시스템에 적합합니다.

03
IT · 개발 · 기획 용어
  • 개발 컨텍스트 스위칭 (Context Switching) CPU가 하나의 프로세스 또는 스레드에서 다른 프로세스 또는 스레드로 실행 제어를 전환하는 과정으로, 이때 이전 프로세스의 상태(컨텍스트)를 저장하고 새 프로세스의 상태를 로드합니다.
  • 개발 블루/그린 배포 (Blue/Green Deployment) 새로운 버전의 애플리케이션을 배포하는 전략 중 하나로, 기존 운영 환경(Blue)과 동일한 새로운 환경(Green)을 구축하여 새 버전을 배포하고, 테스트 완료 후 트래픽을 한 번에 전환하는 방식입니다.
  • IT 데브옵스 (DevOps) 소프트웨어 개발(Development)과 운영(Operations)의 합성어로, 개발과 운영 간의 협업 및 자동화를 통해 소프트웨어 제품의 배포 속도와 품질을 향상시키는 문화적, 기술적 접근 방식입니다.
