#소프트웨어 공학

소프트웨어 개발 생명주기(SDLC) 모델 중, 위험 관리 활동을 반복적으로 수행하며 점진적으로 시스템을 개발해 나가는 모델은?

  1. ①폭포수 모델 (Waterfall Model)
  2. ②나선형 모델 (Spiral Model)
  3. ③프로토타이핑 모델 (Prototyping Model)
  4. ④애자일 모델 (Agile Model)

보기를 클릭해 정답을 확인하세요.

정답: ②

나선형 모델은 폭포수 모델의 순차적 개발 과정과 프로토타이핑의 반복적 개발 과정을 결합한 형태로, 개발 과정에서 발생할 수 있는 위험을 지속적으로 식별하고 관리하는 데 초점을 맞춥니다. 각 주기마다 계획, 위험 분석, 개발, 고객 평가의 네 가지 활동을 반복적으로 수행하여 점진적으로 완성도를 높여갑니다.

03
IT · 개발 · 기획 용어
  • 개발 컨테이너 (Container) 애플리케이션과 그 실행에 필요한 모든 파일(코드, 런타임, 시스템 도구, 라이브러리 등)을 하나로 묶어 어디에서든 일관된 환경에서 실행될 수 있도록 하는 가상화 기술의 한 형태입니다.
  • 개발 도메인 주도 설계 (Domain-Driven Design, DDD) 소프트웨어 개발 시 비즈니스 도메인 전문가와 개발자가 공통의 언어(유비쿼터스 언어)를 사용하여 도메인 모델을 구축하고, 이 모델을 소프트웨어 설계에 반영하는 접근 방식입니다.
  • 기획 그로스 해킹 (Growth Hacking) 제품이나 서비스의 성장을 목표로, 마케팅과 기술을 결합하여 데이터 분석을 기반으로 빠르고 효율적인 실험을 통해 최적의 성장 전략을 찾아내는 방법론입니다.
