#운영체제

운영체제에서 여러 프로세스가 동시에 실행될 때, 각 프로세스가 서로의 메모리 영역을 침범하지 않도록 보호하며, 논리적 주소 공간을 물리적 주소 공간으로 매핑하는 역할을 하는 하드웨어 장치는 무엇인가?

  1. ①DMA 컨트롤러
  2. ②인터럽트 컨트롤러
  3. ③메모리 관리 장치 (MMU)
  4. ④캐시 컨트롤러

보기를 클릭해 정답을 확인하세요.

정답: ③

메모리 관리 장치(MMU, Memory Management Unit)는 CPU가 생성하는 논리적 주소를 물리적 주소로 변환하고, 메모리 접근 권한을 제어하여 프로세스 간의 메모리 침범을 방지하는 하드웨어 장치입니다. 이를 통해 각 프로세스는 독립적인 주소 공간을 사용하는 것처럼 동작할 수 있습니다. DMA 컨트롤러는 CPU 개입 없이 주변장치와 메모리 간 데이터 전송을 담당하고, 인터럽트 컨트롤러는 인터럽트 요청을 처리하며, 캐시 컨트롤러는 캐시 메모리의 동작을 관리합니다.
