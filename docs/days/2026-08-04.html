정답: ③

가상 메모리는 실제 물리 메모리보다 큰 메모리 공간을 사용할 수 있도록 하는 기법입니다. 프로세스 전체를 물리 메모리에 올리지 않고, 필요한 부분만 적재하여 메모리 효율성을 높입니다. 이는 물리 메모리의 한계를 넘어선 프로그램 실행을 가능하게 합니다.

IT · 개발 · 기획 용어
  • 개발 컨테이너 오케스트레이션(Container Orchestration) 다수의 컨테이너화된 애플리케이션을 배포, 관리, 확장 및 네트워킹하는 프로세스를 자동화하는 기술입니다.
  • IT 테크 스택(Tech Stack) 애플리케이션을 구축하고 실행하는 데 사용되는 프로그래밍 언어, 프레임워크, 데이터베이스, 서버 등의 기술 집합을 의미합니다.
  • 기획 퍼널 분석(Funnel Analysis) 사용자가 특정 목표를 달성하기까지의 여러 단계(퍼널)를 거치면서 각 단계에서 얼마나 많은 사용자가 이탈하는지 분석하여 문제점을 파악하는 방법론입니다.
