#운영체제

운영체제에서 메모리 관리 기법 중, '가상 메모리(Virtual Memory)'의 주요 목적과 가장 거리가 먼 것은?

  1. ①물리 메모리의 부족 현상을 해결하여 더 큰 프로그램을 실행할 수 있게 한다.
  2. ②CPU가 직접 물리 메모리에 접근하는 대신, 가상 주소를 통해 접근하게 하여 보안성을 높인다.
  3. ③여러 프로세스가 독립된 주소 공간을 가질 수 있도록 하여 프로세스 간의 충돌을 방지한다.
  4. ④프로그램의 전체 코드를 물리 메모리에 한꺼번에 적재하지 않고 필요한 부분만 적재하여 효율성을 높인다.

정답: ②

가상 메모리는 물리 메모리 부족 해결, 프로세스 간 독립된 주소 공간 제공, 필요한 부분만 메모리에 적재하여 효율성 증대 등의 목적을 가집니다. CPU가 직접 물리 메모리에 접근하는 대신 가상 주소를 통해 접근하게 하는 것은 주소 변환 메커니즘의 일부이며, 가상 메모리의 주요 목적은 아닙니다. 보안성 강화는 가상 메모리의 부수적인 효과일 수 있으나, 가장 주된 목적이라고 보기는 어렵습니다.
