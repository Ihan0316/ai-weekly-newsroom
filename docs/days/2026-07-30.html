#운영체제

운영체제에서 메모리 관리 기법 중, 외부 단편화(External Fragmentation) 문제를 해결하기 위해 주기억장치에 분산된 빈 공간들을 하나로 합치는 작업을 의미하는 것은?

  1. ①페이징(Paging)
  2. ②세그먼테이션(Segmentation)
  3. ③압축(Compaction)
  4. ④스와핑(Swapping)

보기를 클릭해 정답을 확인하세요.

정답: ③

압축(Compaction)은 외부 단편화 문제를 해결하기 위해 주기억장치에 흩어져 있는 작은 빈 공간들을 모아 하나의 큰 빈 공간으로 만드는 작업입니다. 이를 통해 더 큰 프로세스도 메모리에 적재될 수 있습니다. 페이징과 세그먼테이션은 단편화를 줄이는 기법이지만 압축과는 직접적인 관련이 없습니다. 스와핑은 프로세스를 보조기억장치로 옮겨 메모리 공간을 확보하는 기법입니다.

IT · 개발 · 기획 용어
  • 기획 번아웃 (Burnout) 과도한 업무와 스트레스로 인해 신체적, 정신적으로 에너지가 고갈되고 무기력해지는 상태를 의미합니다.
  • 개발 서버리스 (Serverless) 개발자가 서버를 직접 관리할 필요 없이 애플리케이션을 빌드하고 실행할 수 있도록 클라우드 공급자가 서버 인프라를 자동으로 관리해주는 컴퓨팅 모델입니다.
  • 기획 다크 패턴 (Dark Pattern) 사용자를 속이거나 강요하여 의도하지 않은 행동을 유도하는 사용자 인터페이스 디자인 기법을 의미합니다.
