#소프트웨어 공학

소프트웨어 개발 과정에서 코드의 변경 이력을 체계적으로 관리하고, 여러 개발자가 협업하여 작업한 내용을 병합하며, 특정 시점의 코드로 되돌리거나 버전별 차이를 비교할 수 있도록 돕는 시스템은 무엇인가?

보기를 눌러 정답을 확인하세요.

정답: ②

버전 관리 시스템(VCS)은 코드의 변경 이력을 기록하고 관리하여 개발자들이 효율적으로 협업하고, 필요한 경우 이전 버전으로 되돌리거나 변경 사항을 추적할 수 있도록 지원합니다. 이는 소프트웨어 개발의 안정성과 효율성을 크게 향상시킵니다.

03
IT · 개발 · 기획 용어
  • 개발 컨텍스트 스위칭 (Context Switching) CPU가 하나의 프로세스 또는 스레드의 실행을 중단하고 다른 프로세스 또는 스레드의 실행을 시작하기 위해 현재 상태를 저장하고 다음 상태를 로드하는 과정을 의미합니다.
  • 기획 와이어프레임 (Wireframe) 웹사이트나 애플리케이션의 레이아웃과 구성을 시각적으로 표현하는 초기 단계의 설계도로, 기능과 콘텐츠의 배치에 중점을 둡니다.
  • IT 블루/그린 배포 (Blue/Green Deployment) 이전 버전(Blue)과 새 버전(Green)의 환경을 동시에 운영하다가, 모든 트래픽을 새 버전으로 전환하여 무중단 배포를 가능하게 하는 배포 전략입니다.
