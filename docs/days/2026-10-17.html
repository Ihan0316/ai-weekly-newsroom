#데이터베이스

관계형 데이터베이스에서 데이터를 저장하고 관리하는 데 사용되는 가장 기본적인 객체로, 행(Row)과 열(Column)로 구성되며 특정 주제에 대한 정보를 담고 있는 것은 무엇인가?

보기를 눌러 정답을 확인하세요.

정답: ③

테이블은 관계형 데이터베이스에서 데이터를 저장하는 가장 기본적인 단위입니다. 행은 레코드(Record)를, 열은 속성(Attribute)을 나타내며, 이들이 모여 특정 주제에 대한 구조화된 정보를 구성합니다. 뷰, 인덱스, 트리거는 테이블을 보조하거나 특정 기능을 수행하는 데이터베이스 객체들입니다.

IT · 개발 · 기획 용어
  • 개발 도메인 주도 설계 (DDD) 복잡한 소프트웨어 시스템을 개발할 때 비즈니스 도메인 전문가의 지식과 언어를 소프트웨어 모델에 반영하여 비즈니스 로직에 집중하는 개발 접근 방식입니다.
  • 개발 피처 토글 (Feature Toggle) 소프트웨어의 특정 기능을 코드 배포와 독립적으로 켜거나 끌 수 있게 하는 기술로, 새로운 기능의 점진적 출시나 A/B 테스트 등에 활용됩니다.
  • 기획 로드맵 (Roadmap) 제품이나 서비스의 목표 달성을 위한 전략적 계획을 시간 흐름에 따라 시각화한 문서로, 주요 기능 개발 일정, 목표 등을 포함합니다.
