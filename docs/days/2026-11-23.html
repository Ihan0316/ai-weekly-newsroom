#소프트웨어 공학

소프트웨어 개발 과정에서 품질 향상을 위해 코드의 가독성, 유지보수성, 확장성 등을 개선하는 활동을 의미하며, 기능 변경 없이 내부 구조를 개선하는 작업은 무엇인가?

보기를 눌러 정답을 확인하세요.

정답: ②

리팩토링은 소프트웨어의 외부 동작을 변경하지 않으면서 내부 코드를 개선하여 가독성, 유지보수성, 확장성 등을 향상시키는 작업입니다. 이는 버그 수정이나 새로운 기능 추가와는 다르게 코드의 품질을 높이는 데 중점을 둡니다. 이를 통해 장기적으로 소프트웨어의 안정성과 개발 효율성을 높일 수 있습니다.

03
IT · 개발 · 기획 용어
  • IT 데이터 마이닝 (Data Mining) 대규모 데이터 세트에서 유의미한 패턴, 추세, 규칙 등을 발견하여 미래를 예측하고 의사결정에 활용하는 분석 기법입니다.
  • 개발 도메인 주도 설계 (Domain-Driven Design, DDD) 소프트웨어 개발 시 비즈니스 도메인 전문가의 지식과 언어를 중심으로 모델을 구축하고, 이를 소프트웨어 설계에 반영하는 접근 방식입니다.
  • 기획 페르소나 (Persona) 제품이나 서비스를 사용할 가상의 사용자 유형을 설정하여, 그들의 특징, 목표, 행동 패턴 등을 구체적으로 정의한 가상의 인물입니다.
