#데이터베이스

데이터베이스 트랜잭션의 ACID 특성 중, 여러 트랜잭션이 동시에 실행될 때 각 트랜잭션이 독립적으로 실행되는 것처럼 보이게 하여 다른 트랜잭션의 연산에 영향을 받지 않도록 하는 특성은 무엇인가?

보기를 눌러 정답을 확인하세요.

정답: ③

격리성(Isolation)은 여러 트랜잭션이 동시에 실행될 때 각 트랜잭션이 독립적으로 실행되는 것처럼 보이게 하여 서로의 연산에 영향을 받지 않도록 보장하는 특성입니다. 이는 동시성 제어와 관련이 깊습니다. 다른 트랜잭션의 중간 결과를 볼 수 없도록 합니다.

03
IT · 개발 · 기획 용어
  • 개발 인터페이스 분리 원칙 (Interface Segregation Principle, ISP) 클라이언트는 자신이 사용하지 않는 인터페이스에 의존해서는 안 된다는 객체 지향 설계 원칙이다.
  • IT 피처 엔지니어링 (Feature Engineering) 머신러닝 모델의 성능을 향상시키기 위해 원본 데이터로부터 새로운 특징(Feature)을 도출하고 변환하는 과정이다.
  • 기획 유저 스토리 (User Story) 사용자의 관점에서 소프트웨어가 제공해야 할 기능과 가치를 간략하게 서술한 것이다.
