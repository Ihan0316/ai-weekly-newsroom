#데이터베이스

데이터베이스에서 트랜잭션의 ACID 특성 중, 트랜잭션이 부분적으로 실행되다가 실패하더라도 모든 변경 사항을 원래 상태로 되돌려 데이터 일관성을 유지하는 특성은?

  1. ①원자성 (Atomicity)
  2. ②일관성 (Consistency)
  3. ③격리성 (Isolation)
  4. ④영속성 (Durability)

보기를 클릭해 정답을 확인하세요.

정답: ①

원자성(Atomicity)은 트랜잭션 내의 모든 연산은 완전히 성공하거나 완전히 실패해야 함을 의미합니다. 즉, 트랜잭션의 일부만 성공하는 경우는 없으며, 실패 시 모든 변경 사항을 롤백하여 데이터의 일관성을 보장합니다.

IT · 개발 · 기획 용어
  • 개발 컨테이너 오케스트레이션 (Container Orchestration) 다수의 컨테이너를 자동으로 배포, 관리, 확장 및 네트워킹하는 프로세스를 의미하며, 쿠버네티스(Kubernetes)가 대표적인 도구입니다.
  • 개발 피처 플래그 (Feature Flag) 소프트웨어의 특정 기능을 코드 배포 없이 켜거나 끌 수 있게 하여, A/B 테스트나 점진적 기능 출시 등을 가능하게 하는 기술입니다.
  • 기획 퍼널 (Funnel) 고객이 특정 목표(예: 구매, 회원가입)를 달성하기까지 거치는 일련의 단계들을 시각화한 것으로, 각 단계별 전환율을 분석하여 개선점을 찾습니다.
