객체 지향 프로그래밍에서 '캡슐화(Encapsulation)'에 대한 설명으로 가장 적절한 것은?

보기를 눌러 정답을 확인하세요.

정답: ①

캡슐화는 객체의 속성(데이터)과 행위(메서드)를 하나의 단위로 묶고, 외부에서 객체 내부의 세부 구현을 직접 접근하지 못하도록 숨기는 특성입니다. 이를 통해 데이터의 무결성을 유지하고, 코드의 유지보수성을 높일 수 있습니다.

03
IT · 개발 · 기획 용어
  • IT 퍼블릭 클라우드 (Public Cloud) 아마존 웹 서비스(AWS), 마이크로소프트 애저(Azure), 구글 클라우드 플랫폼(GCP)과 같이 서비스 제공업체가 컴퓨팅 리소스를 인터넷을 통해 일반 대중에게 제공하는 클라우드 환경을 의미한다.
  • 기획 데드라인 (Deadline) 특정 작업이나 프로젝트를 완료해야 하는 최종 기한을 의미한다.
  • 개발 기술 부채 (Technical Debt) 단기적인 이점을 위해 장기적인 관점에서 좋지 않은 기술적 결정을 내렸을 때 발생하는 추가적인 작업 비용이나 문제를 의미한다.
