#소프트웨어 공학

소프트웨어 개발에서 '팩토리 메서드 패턴(Factory Method Pattern)'에 대한 설명으로 가장 적절한 것은?

보기를 눌러 정답을 확인하세요.

정답: ①

팩토리 메서드 패턴은 객체 생성을 위한 인터페이스를 정의하고, 실제 객체 생성은 서브클래스에 위임하는 패턴입니다. 이를 통해 객체 생성 로직을 캡슐화하고, 새로운 클래스가 추가되어도 기존 코드를 수정하지 않고 확장할 수 있게 합니다.

03
IT · 개발 · 기획 용어
  • 개발 코드 스플리팅 (Code Splitting) 애플리케이션의 코드를 여러 개의 작은 번들로 나누어 필요할 때만 로드하도록 최적화하는 기법이다.
  • 기획 다크 런치 (Dark Launch) 새로운 기능이나 서비스의 백엔드 시스템을 사용자에게 노출하지 않고 배포하여 실제 환경에서 성능과 안정성을 테스트하는 방식이다.
  • IT 데이터 웨어하우스 (Data Warehouse) 여러 소스에서 수집된 데이터를 통합하고 정제하여 분석 및 보고 목적으로 저장하는 중앙 집중식 저장소이다.
