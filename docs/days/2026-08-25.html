#데이터베이스

관계형 데이터베이스에서 여러 테이블을 연결하여 데이터를 조회할 때, 두 테이블 간의 공통된 속성을 기준으로 행을 결합하는 연산은?

  1. ①SELECT
  2. ②PROJECT
  3. ③JOIN
  4. ④UNION

보기를 클릭해 정답을 확인하세요.

정답: ③

JOIN 연산은 두 개 이상의 테이블에서 공통된 컬럼(속성)을 기준으로 행(레코드)을 연결하여 새로운 결과 집합을 생성합니다. 이를 통해 여러 테이블에 분산된 데이터를 통합하여 조회할 수 있습니다. SELECT는 데이터를 선택하고, PROJECT는 컬럼을 선택하며, UNION은 두 쿼리 결과를 합칩니다.

IT · 개발 · 기획 용어
  • IT 데이터 정규화 (Data Normalization) 데이터베이스 설계 시, 속성(Attribute)의 불필요한 중복을 제거하여 데이터의 일관성과 무결성을 확보하고, 이상(Anomaly) 현상을 방지하기 위해 데이터를 구조화하는 과정입니다.
  • 개발 트랜잭션 (Transaction) 데이터베이스에서 하나의 논리적 기능을 수행하기 위한 하나 이상의 연산들의 집합으로, 모두 성공하거나 모두 실패해야 하는 원자적 단위입니다.
  • 기획 로드맵 (Roadmap) 제품 또는 서비스의 장기적인 비전과 목표를 달성하기 위한 전략적 계획과 단계별 일정을 시각적으로 나타낸 것입니다.
