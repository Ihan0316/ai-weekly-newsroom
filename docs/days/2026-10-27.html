#운영체제

운영체제에서 프로세스 간 통신(IPC)을 위한 기법 중, 서로 다른 프로세스들이 데이터를 공유할 수 있는 메모리 영역을 설정하여 직접 데이터를 주고받는 방식은 무엇인가?

보기를 눌러 정답을 확인하세요.

정답: ③

공유 메모리(Shared Memory)는 여러 프로세스가 접근할 수 있는 메모리 영역을 설정하여 데이터를 직접 공유하는 방식입니다. 이 방식은 다른 IPC 기법에 비해 데이터를 직접 읽고 쓸 수 있어 가장 빠른 통신 속도를 제공합니다. 다만, 동기화 문제가 발생할 수 있어 세마포어(Semaphore)와 같은 동기화 메커니즘이 필요합니다.

03
IT · 개발 · 기획 용어
  • 개발 컨테이너 오케스트레이션(Container Orchestration) 수많은 컨테이너의 배포, 확장, 관리 등을 자동화하여 효율적인 애플리케이션 운영을 가능하게 하는 기술입니다.
  • IT 데이터 레이크하우스(Data Lakehouse) 데이터 레이크의 유연성과 데이터 웨어하우스의 구조화된 데이터 관리 기능을 결합하여, 다양한 데이터 분석 및 활용을 지원하는 아키텍처입니다.
  • 개발 서비스 메시(Service Mesh) 마이크로서비스 아키텍처에서 서비스 간 통신을 관리하고 제어하기 위한 인프라 계층으로, 트래픽 관리, 보안, 관찰 가능성 등의 기능을 제공합니다.
