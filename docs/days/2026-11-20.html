#소프트웨어 공학

소프트웨어 개발 과정에서 변경이 발생했을 때, 해당 변경이 시스템 전체에 미치는 영향을 최소화하고 다른 부분에 파급되지 않도록 하는 설계 원칙은 무엇인가?

보기를 눌러 정답을 확인하세요.

정답: ③

개방/폐쇄 원칙(OCP)은 소프트웨어 개체(클래스, 모듈, 함수 등)는 확장에 대해서는 열려 있어야 하고, 수정에 대해서는 닫혀 있어야 한다는 원칙입니다. 즉, 새로운 기능을 추가할 때는 기존 코드를 수정하지 않고 확장하는 방식으로 개발해야 합니다. 이는 변경으로 인한 부작용을 최소화하고 시스템의 안정성을 높이는 데 기여합니다.

03
IT · 개발 · 기획 용어
  • 개발 플랫폼 엔지니어링 (Platform Engineering) 개발팀이 생산성을 높이고 효율적으로 작업할 수 있도록 셀프 서비스 도구와 서비스를 구축하고 관리하는 분야입니다.
  • 개발 서비스 메시 (Service Mesh) 마이크로서비스 아키텍처에서 서비스 간 통신을 관리하고 제어하기 위한 인프라 계층으로, 주로 사이드카 프록시 형태로 구현됩니다.
  • 기획 퍼널 분석 (Funnel Analysis) 사용자가 특정 목표를 달성하기까지의 과정을 단계별로 나누어 각 단계에서 얼마나 많은 사용자가 이탈하는지 분석하여 문제점을 파악하는 기법입니다.
