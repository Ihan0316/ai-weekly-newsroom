#운영체제

운영체제에서 여러 프로세스가 공유 자원에 동시에 접근할 때, 특정 순서나 제약 조건 없이 자원을 사용하게 되어 발생하는 문제를 무엇이라고 하는가?

  1. ①교착 상태 (Deadlock)
  2. ②경쟁 상태 (Race Condition)
  3. ③세마포어 (Semaphore)
  4. ④뮤텍스 (Mutex)

보기를 클릭해 정답을 확인하세요.

정답: ②

경쟁 상태(Race Condition)는 여러 프로세스가 공유 자원에 동시에 접근할 때, 접근 순서에 따라 실행 결과가 달라질 수 있는 상황을 의미합니다. 이는 데이터 불일치나 예상치 못한 오류를 발생시킬 수 있어 동기화 기법을 통해 해결해야 합니다.

IT · 개발 · 기획 용어
  • IT 컨텍스트 스위칭 (Context Switching) CPU가 하나의 프로세스 또는 스레드에서 다른 프로세스 또는 스레드로 실행 제어를 전환하는 과정을 의미합니다.
  • IT 페이징 (Paging) 운영체제의 메모리 관리 기법 중 하나로, 물리 메모리를 고정된 크기의 페이지 프레임으로 나누고, 프로세스의 논리 주소 공간을 같은 크기의 페이지로 나누어 관리하는 방식입니다.
  • 개발 도메인 (Domain) 소프트웨어 시스템이 해결하고자 하는 특정 업무 영역 또는 문제를 의미하며, 해당 영역의 규칙과 개념을 포함합니다.
