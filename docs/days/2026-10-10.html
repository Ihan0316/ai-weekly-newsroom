#소프트웨어 공학

소프트웨어 아키텍처 패턴 중, 시스템의 각 구성 요소가 독립적인 프로세스로 실행되고, 메시지 큐를 통해 서로 통신하는 분산 시스템 아키텍처는 무엇인가?

  1. ①모놀리식 아키텍처 (Monolithic Architecture)
  2. ②마이크로서비스 아키텍처 (Microservices Architecture)
  3. ③클라이언트-서버 아키텍처 (Client-Server Architecture)
  4. ④계층형 아키텍처 (Layered Architecture)

보기를 클릭해 정답을 확인하세요.

정답: ②

마이크로서비스 아키텍처는 애플리케이션을 작고 독립적인 서비스들로 분리하여 개발하는 방식입니다. 각 서비스는 자체 프로세스에서 실행되며, API나 메시지 큐를 통해 통신하여 유연성과 확장성을 높입니다. 모놀리식 아키텍처는 모든 구성 요소가 하나의 단위로 묶여 실행되는 방식입니다.

IT · 개발 · 기획 용어
  • 개발 리팩토링 (Refactoring) 소프트웨어의 외부 동작은 변경하지 않으면서 내부 구조를 개선하여 코드의 가독성을 높이고 유지보수를 용이하게 하는 작업이다.
  • 기획 페르소나 (Persona) 제품이나 서비스를 사용할 법한 가상의 사용자 유형을 설정하여, 그들의 특징, 목표, 행동 패턴 등을 구체화한 것이다.
  • IT 블록체인 (Blockchain) 분산 원장 기술의 일종으로, 데이터를 '블록' 단위로 묶어 체인 형태로 연결하여 분산 저장하며, 위변조가 어렵도록 암호화 기술을 적용한 것이다.
