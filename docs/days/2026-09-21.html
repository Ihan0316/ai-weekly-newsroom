#운영체제

운영체제에서 여러 프로세스가 동시에 실행될 때, 각 프로세스가 독립적인 주소 공간을 가지도록 하여 다른 프로세스의 메모리 영역을 침범하지 않도록 보호하는 기법은 무엇인가?

  1. ①페이징 (Paging)
  2. ②세그먼테이션 (Segmentation)
  3. ③메모리 보호 (Memory Protection)
  4. ④가상 메모리 (Virtual Memory)

보기를 클릭해 정답을 확인하세요.

정답: ③

메모리 보호는 운영체제가 각 프로세스의 메모리 영역을 분리하여 다른 프로세스가 임의로 접근하거나 수정하지 못하도록 하는 기법입니다. 이는 시스템의 안정성과 보안을 유지하는 데 필수적입니다. 페이징이나 세그먼테이션은 메모리 관리 기법의 일부이며, 가상 메모리는 실제 메모리보다 큰 메모리 공간을 제공하는 개념입니다.
