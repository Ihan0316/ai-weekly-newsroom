정답: ④

테스트는 개발된 소프트웨어가 요구사항을 충족하고 결함 없이 동작하는지 확인하는 과정입니다. 이는 소프트웨어의 품질을 보증하고 사용자에게 신뢰할 수 있는 제품을 제공하기 위해 필수적입니다. 요구사항 분석, 설계, 구현은 테스트 이전의 개발 단계에 해당합니다.

IT · 개발 · 기획 용어
  • 개발 멱등성 (Idempotency) 동일한 연산을 여러 번 수행하더라도 항상 같은 결과를 반환하며 시스템의 상태를 변경시키지 않는 속성을 의미합니다.
  • IT 싱글 사인온 (Single Sign-On, SSO) 한 번의 인증으로 여러 웹사이트나 애플리케이션에 접근할 수 있도록 해주는 인증 방식입니다.
  • 기획 퍼널 분석 (Funnel Analysis) 사용자가 특정 목표(예: 구매, 회원가입)를 달성하기까지 거치는 일련의 단계를 시각화하고 각 단계별 전환율을 분석하여 병목 구간을 파악하는 기법입니다.
