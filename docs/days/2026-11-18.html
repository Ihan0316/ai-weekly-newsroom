#데이터베이스

관계형 데이터베이스에서 데이터를 저장하고 관리하는 데 사용되는 가장 기본적인 객체로, 행(Row)과 열(Column)로 구성되며 특정 주제에 대한 정보를 담고 있는 것은 무엇인가?

보기를 눌러 정답을 확인하세요.

정답: ③

테이블은 관계형 데이터베이스의 핵심 구성 요소로, 데이터를 행과 열의 형태로 구조화하여 저장합니다. 각 행은 하나의 레코드(튜플)를 나타내고, 각 열은 특정 속성(애트리뷰트)을 나타냅니다. 데이터는 테이블 내에서 정의된 스키마에 따라 관리됩니다.

IT · 개발 · 기획 용어
  • 개발 도메인 주도 설계 (DDD) 소프트웨어 개발에서 비즈니스 도메인을 중심으로 모델을 구축하고, 이 모델이 소프트웨어의 핵심이 되도록 하는 접근 방식입니다.
  • 개발 서킷 브레이커 분산 시스템에서 오류가 발생한 서비스에 대한 요청을 일시적으로 차단하여 시스템 전체의 장애 확산을 방지하고 복구를 돕는 디자인 패턴입니다.
  • 개발 카나리 배포 새로운 버전의 소프트웨어를 소수의 사용자에게 먼저 배포하여 문제점을 확인한 후, 점진적으로 모든 사용자에게 확대 적용하는 배포 전략입니다.
