#데이터베이스

관계형 데이터베이스에서 트랜잭션의 ACID 특성 중, 여러 트랜잭션이 동시에 실행될 때 각 트랜잭션이 독립적으로 실행되는 것처럼 보이게 하여 다른 트랜잭션의 연산에 영향을 받지 않도록 하는 특성은?

  1. ①원자성 (Atomicity)
  2. ②일관성 (Consistency)
  3. ③고립성 (Isolation)
  4. ④영속성 (Durability)

보기를 클릭해 정답을 확인하세요.

정답: ③

고립성(Isolation)은 여러 트랜잭션이 동시에 실행될 때, 각 트랜잭션이 다른 트랜잭션의 연산에 영향을 받지 않고 독립적으로 실행되는 것처럼 보이게 하는 특성입니다. 이는 데이터베이스의 동시성 제어와 관련이 깊습니다. 원자성, 일관성, 영속성은 각각 트랜잭션의 다른 중요한 특성을 나타냅니다.

03
IT · 개발 · 기획 용어
  • 개발 컨테이너 오케스트레이션 (Container Orchestration) 여러 컨테이너화된 애플리케이션의 배포, 관리, 스케일링, 네트워킹 등을 자동화하는 기술 또는 도구입니다.
  • 개발 도메인 주도 설계 (Domain-Driven Design, DDD) 소프트웨어 개발 시 실제 비즈니스 도메인을 중심으로 모델을 구축하고, 도메인 전문가와 개발자 간의 긴밀한 소통을 통해 복잡한 비즈니스 로직을 효과적으로 반영하는 접근 방식입니다.
  • 기획 퍼널 분석 (Funnel Analysis) 사용자가 제품이나 서비스를 이용하는 과정(예: 회원가입, 구매)에서 특정 단계를 거쳐 다음 단계로 넘어가는 전환율을 분석하여 사용자 이탈 지점을 파악하고 개선하는 방법론입니다.
