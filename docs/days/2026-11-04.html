#운영체제

운영체제에서 여러 프로세스가 공유 자원에 동시에 접근할 때, 특정 순서나 제약 조건 없이 자원을 사용하게 되어 발생하는 문제를 무엇이라고 하는가?

보기를 눌러 정답을 확인하세요.

정답: ②

경쟁 상태(Race Condition)는 여러 프로세스나 스레드가 공유 자원에 동시에 접근하여 예상치 못한 결과를 초래할 수 있는 상황을 의미합니다. 이는 접근 순서에 따라 결과가 달라질 수 있기 때문에 동기화 메커니즘을 통해 해결해야 합니다.

03
IT · 개발 · 기획 용어
  • IT 가상화 (Virtualization) 물리적인 컴퓨터 리소스(CPU, 메모리, 스토리지 등)를 추상화하여 논리적인 가상 리소스로 통합하거나 분할하여 사용하는 기술입니다.
  • 개발 테스트 더블 (Test Double) 소프트웨어 테스트 시 실제 객체를 사용하기 어려운 경우, 이를 대신하여 테스트를 수행할 수 있도록 만든 가짜 객체(스텁, 목, 페이크 등)를 총칭하는 용어입니다.
  • 기획 린치핀 (Linchpin) 전체 시스템이나 프로젝트에서 핵심적인 역할을 수행하여 없어서는 안 될 매우 중요한 요소나 인물을 지칭하는 용어입니다.
