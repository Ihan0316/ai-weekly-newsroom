#운영체제

운영체제에서 여러 프로세스 간에 CPU와 같은 공유 자원을 할당하는 정책을 결정하고 관리하는 기능은 무엇인가?

보기를 눌러 정답을 확인하세요.

정답: ③

프로세스 스케줄링은 운영체제의 핵심 기능 중 하나로, 여러 프로세스가 한정된 CPU 자원을 효율적으로 나누어 사용할 수 있도록 관리하는 역할을 합니다. 이를 통해 시스템의 전반적인 성능과 응답성을 최적화할 수 있습니다. 다양한 스케줄링 알고리즘이 존재하며, 각 알고리즘은 CPU 활용률, 처리량, 응답 시간 등 특정 목표에 따라 다르게 동작합니다.

03
IT · 개발 · 기획 용어
  • 개발 도메인 주도 설계 (Domain-Driven Design, DDD) 복잡한 소프트웨어 시스템을 개발할 때, 핵심 비즈니스 도메인과 그 로직을 중심에 두고 설계하여 비즈니스 요구사항을 정확히 반영하는 접근 방식입니다.
  • IT 카나리 배포 (Canary Deployment) 새로운 버전의 소프트웨어를 전체 사용자에게 한 번에 배포하지 않고, 소수의 사용자 그룹에게 먼저 배포하여 문제점을 미리 파악하고 점진적으로 확대하는 배포 전략입니다.
  • 개발 백프레셔 (Backpressure) 시스템의 한 구성 요소가 처리할 수 있는 데이터의 양을 초과하여 다른 구성 요소로부터 데이터를 받을 때, 데이터 생산 속도를 조절하도록 요청하는 메커니즘입니다.
