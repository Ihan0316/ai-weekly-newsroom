#운영체제

운영체제에서 프로세스 스케줄링 기법 중, '라운드 로빈(Round Robin)' 스케줄링에 대한 설명으로 가장 적절한 것은?

  1. ①가장 짧은 실행 시간을 가진 프로세스에 우선적으로 CPU를 할당한다.
  2. ②프로세스들이 동일한 시간 할당량(Time Slice)을 부여받아 순서대로 CPU를 사용한다.
  3. ③가장 높은 우선순위를 가진 프로세스에 CPU를 할당하며, 더 높은 우선순위 프로세스 등장 시 선점한다.
  4. ④가장 긴 대기 시간을 가진 프로세스에 CPU를 할당하여 기아 현상을 방지한다.

정답: ②

라운드 로빈 스케줄링은 시분할 시스템에 적합한 선점형 스케줄링 기법입니다. 각 프로세스는 동일한 시간 할당량(Time Slice)을 부여받아 CPU를 사용하며, 할당된 시간 내에 작업을 완료하지 못하면 CPU를 반납하고 다음 프로세스에게 기회를 줍니다. 이는 모든 프로세스에게 공평한 기회를 제공하고 응답 시간을 단축하는 데 효과적입니다.

  • 개발 멱등성 (Idempotence) 여러 번 수행해도 결과가 동일하며 시스템의 상태를 변경하지 않는 연산의 성질을 말합니다.

  • 기획 퍼널 분석 (Funnel Analysis) 사용자가 특정 목표를 달성하기까지 거치는 일련의 단계들을 분석하여 각 단계별 전환율과 이탈 지점을 파악하는 기법입니다.
