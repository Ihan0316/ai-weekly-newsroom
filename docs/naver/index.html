• 컨테이너 오케스트레이션 (개발)
  여러 개의 컨테이너화된 애플리케이션의 배포, 관리, 스케일링 및 네트워킹을 자동화하는 기술이다.

• 데이터 레이크 (IT)
  정형, 비정형 데이터를 포함한 모든 종류의 데이터를 원래 형식 그대로 저장하고 분석할 수 있는 중앙 집중식 저장소이다.

• 퍼널 분석 (기획)
  사용자가 특정 목표(예: 구매)에 도달하기까지의 여러 단계를 시각화하여 각 단계별 전환율과 이탈 지점을 파악하는 분석 기법이다.
