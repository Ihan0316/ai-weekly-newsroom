2. macOS에서 Touch ID로 SSH 키 설정하기
출처: GeekNews
Mac의 Secure Enclave에 추출할 수 없는 개인 키를 만들고, SSH 인증 때마다 Touch ID로 사용을 승인하는 구성이 가능합니다. 기본 제공 도구로 신원 생성, SSH 에이전트 등록, 공개 키 확인까지 명령 3개로 설정할 수 있으며 GitHub의 SSH 인증에도 적합합니다.
주요 내용: Secure Enclave와 Touch ID를 사용하는 이유 / 명령 3개로 설정하기 / CryptoTokenKit 신원과 키 옵션

🧠 오늘의 퀴즈 (정보처리기사)
━━━━━━━━━━━━━━━━━━━━
[소프트웨어 공학] 소프트웨어 개발에서 '형상 관리(Configuration Management)'의 주요 목적과 가장 거리가 먼 것은?
① 소프트웨어 변경 사항을 체계적으로 추적하고 통제한다.
② 여러 개발자가 동시에 작업할 때 발생하는 충돌을 방지하고 통합을 지원한다.
③ 소프트웨어의 특정 버전을 식별하고 해당 버전으로 복원할 수 있도록 한다.
④ 개발된 소프트웨어의 최종 사용자 만족도를 측정하고 개선 방안을 도출한다.

정답: 4번
해설: 형상 관리는 소프트웨어 개발 과정에서 발생하는 변경 사항을 체계적으로 관리하여 소프트웨어의 무결성과 일관성을 유지하는 것을 목표로 합니다. 버전 관리, 변경 제어, 형상 식별 등이 주요 활동이며, 사용자 만족도 측정은 주로 요구사항 분석이나 테스트 단계에서 다루는 내용입니다.

📖 오늘의 IT 용어
━━━━━━━━━━━━━━━━━━━━

• 블로커 (Blocker) (개발)
  소프트웨어 개발 과정에서 특정 작업을 진행할 수 없도록 완전히 막는 심각한 문제나 이슈를 의미한다.

• 도메인 주도 설계 (DDD, Domain-Driven Design) (개발)
  소프트웨어 개발 시 실제 비즈니스 도메인에 대한 깊은 이해를 바탕으로 도메인 모델을 구축하고 이를 소프트웨어 아키텍처에 반영하는 접근 방식이다.

• 온보딩 (Onboarding) (기획)
  신규 사용자가 제품이나 서비스를 처음 접했을 때, 쉽고 효과적으로 적응하고 활용할 수 있도록 돕는 일련의 과정을 의미한다.
