🧠 오늘의 퀴즈 (정보처리기사)
━━━━━━━━━━━━━━━━━━━━
[데이터베이스] 데이터베이스 관리 시스템(DBMS)에서 트랜잭션의 ACID 특성 중, 트랜잭션이 성공적으로 완료된 후에는 해당 변경 사항이 영구적으로 저장되어 어떤 시스템 오류에도 손실되지 않음을 보장하는 특성은?
① 원자성 (Atomicity)
② 일관성 (Consistency)
③ 고립성 (Isolation)
④ 영속성 (Durability)

정답: 4번
해설: 영속성(Durability)은 트랜잭션이 성공적으로 완료되면 그 결과는 영구적으로 데이터베이스에 반영되어 어떤 시스템 장애에도 손실되지 않음을 보장하는 특성입니다. 이는 데이터의 안정적인 저장을 의미합니다. 트랜잭션의 ACID 특성은 데이터베이스의 신뢰성을 보장하는 핵심 요소입니다.

📖 오늘의 IT 용어
━━━━━━━━━━━━━━━━━━━━

• 데드록 (Deadlock) (개발)
  두 개 이상의 프로세스나 스레드가 서로 상대방이 점유하고 있는 자원을 기다리느라 무한정 대기하는 상태를 말합니다.

• 로드밸런서 (Load Balancer) (IT)
  서버로 들어오는 네트워크 트래픽을 여러 서버에 분산하여 특정 서버에 부하가 집중되지 않도록 하는 시스템입니다.

• 애자일 (Agile) (기획)
  소프트웨어 개발 방법론 중 하나로, 변화에 유연하게 대응하고 고객과의 지속적인 소통을 통해 빠르게 결과물을 만들어내는 데 초점을 맞춥니다.
