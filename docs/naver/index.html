🧠 오늘의 퀴즈 (정보처리기사)
━━━━━━━━━━━━━━━━━━━━
[소프트웨어 공학] 소프트웨어 개발 방법론 중, 요구사항의 변화에 유연하게 대응하며, 짧은 주기의 반복적인 개발을 통해 점진적으로 소프트웨어를 완성해 나가는 접근 방식은 무엇인가?
① 워터폴 모델 (Waterfall Model)
② 애자일 (Agile)
③ 나선형 모델 (Spiral Model)
④ V 모델 (V-Model)

정답: 2번
해설: 애자일(Agile) 방법론은 변화하는 요구사항에 민첩하게 대응하기 위해 짧은 개발 주기를 반복하며 소프트웨어를 점진적으로 개발합니다. 고객과의 지속적인 소통과 피드백을 통해 최종 제품의 만족도를 높이는 데 중점을 둡니다. 이는 계획 중심의 워터폴 모델과 대비되는 특징을 가집니다.

📖 오늘의 IT 용어
━━━━━━━━━━━━━━━━━━━━

• 컨테이너 오케스트레이션 (Container Orchestration) (개발)
  다수의 컨테이너화된 애플리케이션의 배포, 관리, 확장 및 네트워킹을 자동화하는 기술 또는 시스템을 의미합니다.

• 도메인 주도 설계 (Domain-Driven Design, DDD) (개발)
  소프트웨어 개발 시 비즈니스 도메인 전문가와 개발자 간의 긴밀한 협력을 통해 복잡한 비즈니스 로직을 코드에 반영하고, 도메인 모델을 중심으로 시스템을 설계하는 접근 방식입니다.

• 온보딩 (Onboarding) (기획)
  새로운 사용자나 직원이 제품, 서비스 또는 조직에 성공적으로 적응하고 가치를 경험할 수 있도록 돕는 일련의 과정이나 경험을 의미합니다.
